# TexasHoldem AI

面向德州扑克学习者的 AI 对战 Demo。当前版本支持 2–4 人连续牌局、四种 AI 模式与 DeepSeek 决策；API 不可用或返回非法行动时，会自动切换本地规则 AI，保证演示不中断。

## 第三阶段功能

- 线下对战：全部对手使用本地默认 AI，强制不调用 DeepSeek，不消耗 API Token。
- 简单模式：全部对手使用“菜鸟”风格。
- 进阶模式：对手在内部使用保守或激进策略，页面统一标记为“进阶”。
- 困难模式：全部对手使用“高手”风格，结合蒙特卡洛胜率、底池赔率、SPR、最低防守频率、位置和建议下注尺度进行 GTO 启发式决策。
- 自定义模式：可为每个 AI 座位选择菜鸟、进阶或高手；也可点击“以随机 AI 开始新对局”，按当前人数秘密分配风格并直接开局。随机结果不进入侧边栏选择框，牌桌昵称旁也不显示风格，整场连续对战保持保密。
- AI 姓名右侧是唯一类型标记；DeepSeek 不可用时，该标记变为“默认”。
- AI 不展示行动理由，也不会把其他玩家的隐藏手牌或牌堆内容发送给模型。
- 所有模型输出都会经过合法行动和下注金额校验，非法输出直接由默认 AI 接管。
- 支持庄家轮换、盲注、完整下注轮、反复加注、全下跑牌、未跟注筹码退还、主池/边池及多人平分结算。
- 行动停留、阶段切换和公共牌翻转采用非阻塞计时；页面不会因等待动画而整体变灰。新一局手牌从桌面中央以位移和淡入效果发往各座位，公共牌使用同类轻量动效，不包含手部模型。

高手 AI 是适合演示和陪练的 GTO 启发式实现，并非离线求解器或严格纳什均衡解算器。

## 第四阶段功能

- 高级牌局决策记录：后台记录每次行动前后的阶段、底池、下注压力、筹码与公开牌面；页面底部保留默认折叠的高级查看入口。
- 实时策略提示：只在联网模式、轮到真人玩家时显示；点击后进行 1500 次蒙特卡洛抽样，同时展示基础牌面胜率和结合对手公开行动温和加权的参考胜率。行动模型不读取隐藏手牌、保留诈唬可能，并限制最大调整幅度。
- AI深度复盘：只在联网模式显示；当前会话至少完成 5 局后，才可由玩家点击生成从第一局到最新一局的累计分析，包括整体画像、重复模式、具体牌局证据和未来 3～5 局训练计划。
- 数据面板：默认折叠，跨新对局保留当前会话数据；8 局形成会话级稳定画像，以通俗中文展示翻前参与、主动加注、受压弃牌、翻后进攻、全下、摊牌和下一轮训练重点。
- 结构化记录和发送给 DeepSeek 的内容都不包含对手未公开手牌或牌堆。
- 线下对战不显示联网提示与复盘按钮，继续保持零 API 调用。

实时策略提示和 AI 深度复盘不提供本地分析替代；API 不可用时会直接提示暂不可用。

## 牌桌 UI

- 深绿色椭圆牌桌采用轻度透视，玩家头像框全部位于桌外；桌内只呈现手牌与公共牌。
- 2 人、3 人和 4 人牌局分别使用独立座位布局；其他玩家始终先显示两张牌背，只有摊牌或全下公开时才显示牌面。
- 当前底池使用牌桌左侧的独立 HUD，不与桌面重叠。
- 实时策略提示、AI 深度复盘、数据面板、行动记录和高级决策记录集中在右侧滚动面板中。
- 实时策略正文只有玩家点击“实时策略提示”后才会生成并显示。

## 新手引导

- 侧边栏“游戏规则”默认折叠，完整说明目标、行动顺序、四个下注阶段、可选行动、全下、退还筹码、主池/边池、摊牌与全部牌型。
- “示例对局”提供固定四人教学牌局：真人固定持有 A♠、K♠，教程对手只会跟注或过牌，固定公共牌会让真人组成皇家同花顺。
- 示例对局的实时策略提示为本地固定教学内容，全程不调用 DeepSeek，也不会计入玩家画像或累计深度复盘。
- 当下注已经完全结束并进入全下跑牌时，立即公开所有未弃牌玩家的手牌，再按当前阶段逐步补齐五张公共牌；已弃牌手牌始终隐藏。

## DeepSeek API

API Key 只从 Windows 用户环境变量读取，不写入项目文件：

```text
DEEPSEEK_API_KEY=你的 API 密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=你选择的通用模型
```

修改环境变量后需要关闭并重新打开终端。不要把 API Key 写入源码、截图、日志或 Git 仓库。

## 如何运行

在 PowerShell 中进入项目目录后启动：

```powershell
Set-Location -LiteralPath D:\Zikky\Documents\TexasHoldem
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

保持终端窗口运行，并打开命令输出中的本地地址，通常是 `http://localhost:8501`。网页由本机 Python 进程提供，关闭终端中的 Streamlit 进程后网页也会停止。

## 如何测试

```powershell
Set-Location -LiteralPath D:\Zikky\Documents\TexasHoldem
py -m pytest -q
```

重点手工验证：

1. 分别选择线下、简单、进阶、困难、自定义模式并开始新对局。
2. 确认 AI 姓名右侧只出现一个难度标记，行动栏不重复显示。
3. 临时移除 `DEEPSEEK_API_KEY` 后重启应用，确认 AI 姓名右侧变为“默认”，牌局仍可继续。
4. 自定义模式选择不同难度，确认对应座位显示正确标记。
5. 展开“游戏规则”，确认规则可阅读；点击“示例对局”，查看一次实时策略提示并完成固定牌局。
6. 在任意阶段让所有未弃牌玩家进入全下，确认手牌立即公开，已有公共牌不消失，剩余公共牌逐街发出。
7. 分别开始 2 人、3 人和 4 人牌局，确认头像框位于桌外、隐藏手牌显示两张牌背，底池 HUD 不压住桌面。
